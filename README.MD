# Лабораторная 2: Структура базы данных и подключение к бэкенду

## Цель работы
- Разработка структуры базы данных.
- Подключение базы данных к бэкенду.
- Работа с ORM и SQL.

## Описание задания
1. Разработать структуру базы данных PostgreSQL по теме работы:
   - Использовать таблицу услуг в страницах приложения.
   - Наполнить таблицы данными через Django Admin или Adminer.
   - Создать ER-диаграмму в StarUML с таблицами, связями, типами столбцов, первичными и внешними ключами.

2. Реализовать функционал:
   - Получение и поиск услуг.
   - Добавление услуги в текущую заявку (статус "черновик") через ORM.
   - Логическое удаление заявки через SQL UPDATE.
   - Просмотр содержимого заявки через ORM.
   - Всего 5 HTTP методов:
     - 3 GET-запроса.
     - 1 POST добавления услуги в заявку через ORM.
     - 1 POST удаления заявки через SQL.

3. Правила работы с заявкой:
   - При отсутствии заявки черновик создается только при добавлении услуги.
   - Услуга добавляется сразу, если черновик уже существует.
   - Просматривать удаленные заявки нельзя.

## Порядок показа
1. Показать панель администратора Django/Adminer.
2. Добавить новую услугу и проверить данные через SELECT в БД.
3. Показать 3 страницы приложения:
   - Выполнить поиск.
   - Удалить заявку и перейти по URL удаленной заявки.
   - Добавить две услуги в заявку, показать содержимое заявки.
4. Показать изменение полей заявки в БД и результат в приложении.
5. Показать код моделей, составной уникальный ключ, 4 контроллера через ORM, удаление заявки через SQL UPDATE.

## Контрольные вопросы
- Виды БД, SQL-запросы, курсоры.
- ORM, модель и миграции.
- Чистая архитектура.
