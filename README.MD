# Лабораторная 1: Дизайн приложения и базовая шаблонизация

## Цель работы
- Выбор варианта/темы на весь курс.
- Знакомство с разработкой бэкенда.
- Разработка дизайна для 3 страниц приложения.

## Описание задания
1. Разработать дизайн трех страниц приложения в Figma:
   - Повторить стилистику существующего ресурса.
   - Использовать 3 цвета с точными кодами, эффекты hover, карточки для услуг.
   - Подобрать реальные данные для темы.

2. Создать базовый интерфейс приложения:
   - **Страница списка услуг**: карточки с наименованием, ценой (или датой/мощностью), изображением и элементом-карточкой текущей заявки (корзина).
   - **Страница услуги**: подробная информация по выбранной услуге.
   - **Страница заявки**: отображение состава заявки с отдельными карточками услуг, поля для количества и результата вычислений.

3. Навигация:
   - Header с кнопкой "Домой" для возврата к списку услуг.
   - Поле input для фильтрации списка услуг на сервере по одному из полей (наименование, цена, дата).

4. Требования к функционалу:
   - Всего 3 GET-запроса.
   - Две модели-коллекции: массив услуг и словарь заявки.
   - Данные берутся из коллекций, без использования БД.
   - Изображения подгружаются из Minio.
   - CSS вынести в отдельный файл.
   - JavaScript не использовать.

## Порядок показа
1. Показать задание по теме.
2. Показать дизайн 3 страниц в Figma и аналогичный интерфейс в приложении.
3. Продемонстрировать сайт, откуда копировался дизайн, с объяснением элементов CSS.
4. Показать три страницы приложения с фильтром и GET-запросами через вкладку Network:
   - Объяснить URL, параметры фильтрации/поиска, id заявки и услуг.
   - Для страницы списка услуг показать в HTML: id заявки, количество в корзине, URL изображений из Minio.
5. Показать роутинг: 3 URL и три контроллера, объяснить фильтрацию/поиск.

## Контрольные вопросы
- MVT и компоненты MVC в лабораторной.
- Django и шаблонизация.
- HTTP, модель OSI, Web, HTML.
